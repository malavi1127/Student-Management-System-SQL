# Student Management System (SQL)

## About This Project

I created this project to practice and improve my SQL and database management skills.

The main idea behind this project is to build a simple Student Management System where student details, course information, and enrollment records can be stored and managed using a relational database.

While working on this project, I focused on understanding how databases are designed in real-world applications and how SQL queries are used to retrieve and manage data.

---

## What This Project Does

- Stores student information
- Stores course details
- Maintains student course enrollment records
- Creates relationships between different tables
- Performs data retrieval using SQL queries
- Helps in understanding database operations

## Database Structure

The database contains tables like:

### Students Table

Contains basic student details such as:

- Student ID
- Student Name
- Gender
- Email
- Phone Number

### Courses Table

Contains course-related information:

- Course ID
- Course Name
- Course Duration

### Enrollments Table

Connects students with courses:

- Enrollment ID
- Student ID
- Course ID
- Enrollment Date
